# Thesis Appendix

This repository contains supplementary materials for my PhD thesis, ["Diversification Models and Neural Inference"](https://github.com/EvoLandEco/Thesis), organized by chapter.

## Structure

- **Chapter2/**
  - Additional figures
  - Animated GIFs

- **Chapter3/**
  - Data and code used for analyses and plotting

- **Chapter4/**
  - Data and code used for analyses and plotting

## Git LFS for large files

Some large `.RData` files are tracked with **Git LFS**. If you clone this repository, install Git LFS first to ensure these files download correctly. See: https://git-lfs.com/

## Notes

- Files are provided to support reproduction of analyses and to offer additional visual material beyond the main thesis.
- Chapter folders are independent; refer to the corresponding thesis chapter for context.
